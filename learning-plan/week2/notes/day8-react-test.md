## 测试概述

成功实现了简化版 ReActAgent，验证了思考-行动-观察循环。

### ReAct 核心流程

```
┌─────────────────────────────────────────────────────────────────┐
│                    ReAct 执行循环                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│    ┌──────────┐                                                │
│    │  用户问题 │                                                │
│    └────┬─────┘                                                │
│         ↓                                                      │
│    ┌──────────┐                                                │
│    │  Thought │ ← 思考分析问题，规划下一步                       │
│    └────┬─────┘                                                │
│         ↓                                                      │
│    ┌──────────┐                                                │
│    │  Action  │ ← 选择工具调用或 Finish                         │
│    └────┬─────┘                                                │
│         ↓                                                      │
│    ┌───────────┐                                               │
│    │Observation│ ← 观察工具返回结果                             │
│    └─────┬─────┘                                               │
│          │                                                     │
│          ├─ 信息不够 ──→ 继续循环（回到 Thought）               │
│          │                                                     │
│          └─ 信息足够 ──→ Finish[最终答案]                       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

PROMPT_TEMPLATE = """你是一个具备推理和行动能力的AI助手。

## 可用工具
{tools}

Thought: 你的思考过程

## ReAct vs SimpleAgent 对比

| 特性 | SimpleAgent | ReActAgent |
|------|-------------|------------|
| 执行模式 | 单次调用 | 循环迭代 |
| 工具调用 | 检测 `[TOOL_CALL:...]` | 解析 `工具名[参数]` |
| 历史管理 | 存储对话历史 | 存储行动-观察历史 |
| 推理能力 | 弱（依赖提示词） | 强（显式思考步骤） |
| 适用场景 | 简单问答 | 需要多步推理的任务 |

---

## 关键理解

1. **ReAct 本质**：通过显式的 Thought-Action-Observation 循环，让 LLM 有机会"思考"和"反思"

2. **历史的作用**：每次循环都将之前的 Action-Observation 加入提示词，让 LLM 了解已完成的工作

3. **Finish 条件**：LLM 自己判断何时有足够信息，体现"自省"能力

4. **工具选择**：LLM 根据任务自主选择合适工具，体现"规划"能力
