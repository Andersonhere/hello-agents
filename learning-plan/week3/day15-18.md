**MCP 核心概念** 🧠：

```
MCP (Model Context Protocol) = 模型上下文协议

核心价值：
- 统一的工具接口标准
- Agent 可以动态发现和调用工具
- 支持多种传输方式（stdio、SSE、HTTP）

关键概念：
┌─────────────────────────────────────────────────────────────┐
│                    MCP 核心概念                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  MCP Server（服务器）                                        │
│  - 提供工具、资源、提示词                                     │
│  - 独立进程，通过 stdio/HTTP 通信                            │
│                                                             │
│  MCP Client（客户端）                                        │
│  - 连接服务器，调用工具                                       │
│  - Agent 通过 Client 使用工具                                │
│                                                             │
│  Transport（传输层）                                         │
│  - stdio：标准输入输出（本地）                                │
│  - SSE：Server-Sent Events                                  │
│  - HTTP：网络通信                                            │
│                                                             │
│  Tools（工具）                                               │
│  - 可被 Agent 调用的函数                                      │
│  - 有名称、描述、参数 schema                                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

agent = SimpleAgent(name="助手", llm=HelloAgentsLLM())

# 连接文件系统 MCP 服务器
fs_tool = MCPTool(
    name="filesystem",
    description="访问本地文件系统",
    server_command=["npx", "-y", "@modelcontextprotocol/server-filesystem", "."]
)
agent.add_tool(fs_tool)

# 连接自定义 Python MCP 服务器
custom_tool = MCPTool(
    name="custom_server",
    description="自定义业务逻辑服务器",
    server_command=["python", "my_mcp_server.py"]
)

### 任务 6：集成 MCP 到 Agent

**你需要做的事情** 🧠：

创建一个集成了 MCP 工具的 Agent：

```python
# mcp_agent.py
import os
from dotenv import load_dotenv
from hello_agents import SimpleAgent, HelloAgentsLLM
from hello_agents.tools import MCPTool

load_dotenv()

def create_mcp_agent():
    """创建集成了 MCP 工具的 Agent"""
    
    # 1. 创建 LLM
    llm = HelloAgentsLLM()
    
    # 2. 创建 Agent
    agent = SimpleAgent(
        name="MCP 智能助手",
        llm=llm,
        system_prompt="""你是一个功能强大的智能助手。

你拥有以下能力：
1. 数学计算（加减乘除）
2. 系统信息查询
3. 文件系统操作

请根据用户需求选择合适的工具完成任务。"""
    )
    
    # 3. 添加内置 MCP 工具
    builtin_mcp = MCPTool(name="builtin")
    agent.add_tool(builtin_mcp)
    
    # 4. 可选：添加文件系统 MCP 工具
    # fs_mcp = MCPTool(
    #     name="filesystem",
    #     server_command=["npx", "-y", "@modelcontextprotocol/server-filesystem", "."]
    # )
    # agent.add_tool(fs_mcp)
    
    return agent


def main():
    print("=" * 50)
    print("MCP 智能助手")
    print("=" * 50)
    
    agent = create_mcp_agent()
    
    # 测试用例
    test_cases = [
        "帮我计算 123 * 456",
        "获取系统信息",
        "向我问好，名字叫小明"
    ]
    
    for question in test_cases:
        print(f"\n问题: {question}")
        print("-" * 40)
        response = agent.run(question)
        print(f"回答: {response}")


if __name__ == "__main__":
    main()
```

```bash

```
