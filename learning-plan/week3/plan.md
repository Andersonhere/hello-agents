## 📚 核心知识点

### 1. MCP 协议

```
┌─────────────────────────────────────────────────────────────┐
│                    MCP 协议架构                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   ┌─────────────┐        ┌─────────────┐                   │
│   │   Agent     │ ←────→ │  MCP Client │                   │
│   └─────────────┘        └──────┬──────┘                   │
│                                 │                          │
│                          MCP Protocol                       │
│                                 │                          │
│   ┌─────────────┐        ┌──────↓──────┐                   │
│   │  Tools API  │ ←────→ │  MCP Server │                   │
│   └─────────────┘        └─────────────┘                   │
│                                                             │
│   MCP Server 类型：                                         │
│   - 内置演示服务器（add, subtract...）                       │
│   - 文件系统服务器                                           │
│   - GitHub 服务器                                            │
│   - 自定义服务器                                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2. 记忆系统

| 记忆类型 | 作用 | 实现方式 |
|----------|------|----------|
| 短期记忆 | 当前对话上下文 | 消息列表 |
| 工作记忆 | 正在处理的信息 | 状态管理 |
| 长期记忆 | 持久化知识 | 向量数据库 |

### 3. RAG 流程

```
文档 → 分块 → 向量化 → 存储
                      ↓
问题 → 向量化 → 相似度检索 → 相关文档
                              ↓
                    问题 + 相关文档 → LLM → 回答
```
