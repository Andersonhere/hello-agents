## 📝 学习内容

### Agent 核心概念

**Agent 定义**：
Agent 是能够感知环境、做出决策、执行行动的智能体。它通过 LLM 作为"大脑"，结合工具扩展能力边界。

**Agent 核心组成**：
1. **LLM（大脑）**：理解和生成语言，进行推理和决策
2. **Memory（记忆）**：存储上下文信息，维护对话历史
3. **Tools（工具）**：扩展能力边界，执行具体操作
4. **Planning（规划）**：分解和执行任务，制定行动计划

---

### FirstAgentTest.py 执行流程

```
用户问题
    ↓
┌─────────────────────────────────────┐
│ 1. 构建系统提示词（包含工具描述）     │
│ 2. 构建消息列表（system + user）     │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│ 3. 调用 LLM 获取响应                 │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│ 4. 解析 Thought 和 Action           │
│    - 正则匹配 Thought: (.+)         │
│    - 正则匹配 Action: (.+)          │
│    - 检测直接 Finish[答案]          │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│ 5. 执行工具或返回答案                │
│    - 如果是 Finish → 返回答案       │
│    - 如果是工具调用 → 执行工具       │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│ 6. 记录 Observation 到历史          │
│ 7. 循环到步骤 3（最多 max_steps）    │
└─────────────────────────────────────┘
```

**关键理解**：
1. **消息结构**：system 提示词 + user 问题 + history 观察
2. **循环机制**：通过 history 记录工具结果，让 LLM 知道上一步的结果
3. **终止条件**：检测到 Finish 或达到最大步数

---

### ReAct 循环理解

**Thought（思考）**：
LLM 分析当前情况，决定下一步行动。例如：
```
Thought: 用户想知道北京今天的天气情况，需要调用天气查询工具。
```

**Action（行动）**：
LLM 输出要执行的动作，有两种形式：
1. 调用工具：`Action: get_weather(city="北京")`
2. 返回答案：`Finish[北京今天天气晴朗，气温29摄氏度]`

**Observation（观察）**：
工具执行后的结果，添加到历史记录中：
```
Observation: 北京当前天气：Sunny，气温29摄氏度
```

