# AI 辅助提示词：项目指导

> 用于让 AI 帮助进行项目设计和开发

---

## 项目设计

```markdown
我想开发一个项目：

项目描述：
[描述项目功能]

需求：
- [需求1]
- [需求2]

技术约束：
- [约束1]
- [约束2]

请帮我：
1. 设计项目架构（目录结构）
2. 规划核心模块
3. 设计关键接口
4. 给出开发步骤
5. 识别技术风险
```

---

## 功能实现

```markdown
我需要实现一个功能：

功能描述：
[描述功能]

当前代码：
[粘贴代码]

请帮我：
1. 设计实现方案
2. 编写核心代码
3. 添加错误处理
4. 提供使用示例
```

---

## 技术选型

```markdown
我需要为项目选择技术方案：

场景：
[描述场景]

备选方案：
- 方案A：[描述]
- 方案B：[描述]

请帮我：
1. 对比各方案优缺点
2. 分析适用场景
3. 给出选择建议
4. 提供最佳实践
```

## 文档编写

```markdown
请帮我编写项目文档：

项目信息：

- 主要功能：
- 技术栈：

请生成：
1. README.md 模板
2. API 文档
3. 使用示例
```
