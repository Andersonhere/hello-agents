# AI 辅助提示词：调试帮助

> 用于让 AI 帮助调试和解决问题

---

## 错误诊断

```markdown
我的代码运行出错，请帮我诊断：

代码：
[粘贴代码]

错误信息：
[粘贴完整错误信息]

环境信息：
- Python 版本：
- 操作系统：
- 相关依赖版本：

请帮我：
1. 分析错误原因
2. 提供解决方案
3. 给出修复代码
4. 说明如何避免类似问题
```

---

## 环境问题

```markdown
我遇到环境配置问题：

问题描述：
[描述问题]

我的配置：
- 操作系统：
- Python 版本：
- 已安装的包：[pip list 关键输出]

尝试过的方法：
1. [方法1]
2. [方法2]

请帮我：
1. 分析可能的原因
2. 提供解决步骤
3. 给出验证方法
```
