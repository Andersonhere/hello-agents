# AI 辅助提示词：代码解释

> 用于让 AI 帮助理解和解释代码

---

## 基础代码解释

```markdown
请详细解释以下代码：

[粘贴代码]

请说明：
1. 这段代码的整体功能是什么？
2. 核心类/函数的作用
3. 关键变量的含义
4. 执行流程
5. 注意事项
```

---

## 执行流程分析

```markdown
请分析以下代码的执行流程：

[粘贴代码]

请用流程图或步骤说明：
1. 入口点在哪里？
2. 每个步骤做什么？
3. 数据如何流转？
4. 有哪些分支条件？
5. 如何结束？
```
