# Hello-Agents 学习计划总览

> 目标：**就业导向** —— 在一个月内系统掌握 AI Agent 后端开发，产出可上简历的项目

> 📌 **本计划已于 Week 1 完成后基于实际情况修订**，详见文末 v2 修订说明

---

## 📊 项目概览

| 项目 | 内容 |
|------|------|
| **学习周期** | 4周（30天） |
| **每日投入** | 约 4 小时 |
| **总学习时长** | 约 120 小时 |
| **学习目标** | 求职 Agent 工程师 / 公司 Agent 提效 |
| **核心产出** | 1 个 GitHub 项目 + 4 篇博客 + 演示视频 |
| **环境约束** | 仅有 LLM API key（无其他外部 API） |

## 🎯 学习目标

### 知识目标
- [x] 理解 Agent 核心概念和经典范式（ReAct、Reflection、Plan-and-Solve）
- [ ] 吃透 HelloAgents 框架内部实现（手写极简版）
- [ ] **掌握工业界主流 LangGraph**（StateGraph、Checkpointer）
- [ ] 熟悉 MCP 协议（用 + 写）
- [ ] 掌握 RAG 全流程（chunking、embedding、检索、注入）
- [ ] 理解记忆系统（短期/工作/长期）
- [ ] **掌握 Tracing 与 Agent 评估方法**（LangSmith）

### 技能目标
- [ ] 能用 LangGraph 独立构建后端 Agent
- [ ] 能写一个 MCP server 暴露自定义工具
- [ ] 能基于 trace 定位并优化 prompt
- [ ] 能交付一个具备 README、架构图、测试的项目

### 产出目标（**简历素材**）
- [ ] GitHub 项目：本地知识库 Agent（公开仓库）
- [ ] 4 篇技术博客（每周一篇）
- [ ] 5 分钟项目讲解视频
- [ ] 设计文档 DESIGN.md
- [ ] 评估报告（含 trace 截图、优化前后对比）

## 🗓️ 四周计划总览

### Week 1：环境搭建 + 快速入门 ✅ 已完成
- **主题**：搭建开发环境，运行第一个 Agent
- **重点**：理解 ReAct/Reflection/Plan-Solve 范式
- **产出**：三种范式 demo 运行成功

### Week 2：HelloAgents 深入 + LangGraph 专攻
- **主题**：吃透框架内部 + 掌握工业标准 LangGraph
- **重点**：手写极简版 + 双框架实现同一 Agent
- **产出**：mini_react_agent.py + LangGraph 实现 + **对比博客**

### Week 3：MCP + 记忆 + RAG + Tracing
- **主题**：构建生产级 Agent 必备四件套
- **重点**：手写 MCP server、RAG 全流程、LangSmith Tracing
- **产出**：四件套整合的 baseline Agent

### Week 4：本地知识库 Agent 项目
- **主题**：后端 Agent 项目实战
- **重点**：Day 22 设计文档 → 实现 → 评估 → 包装
- **产出**：**GitHub 公开项目 + README + 视频 + 复盘博客**

10. **新增简历素材清单** —— 学习直接服务于就业
