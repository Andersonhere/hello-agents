# Hello-Agents 学习计划总览

> 目标：在一个月内系统掌握 AI Agent 开发，从理论到实践完成一个完整项目

---

## 📊 项目概览

| 项目 | 内容 |
|------|------|
| **学习周期** | 4周（30天） |
| **每日投入** | 约 2.5 小时 |
| **总学习时长** | 约 75 小时 |
| **核心产出** | 1个完整 Agent 项目 + 学习笔记 |

---

## 🎯 学习目标

### 知识目标
- [ ] 理解 Agent 核心概念和经典范式（ReAct、Reflection、Plan-and-Solve）
- [ ] 掌握 HelloAgents 框架的使用和扩展
- [ ] 熟悉 MCP 协议和工具集成
- [ ] 了解记忆系统、RAG 基本原理

### 技能目标
- [ ] 能够独立构建单智能体应用
- [ ] 能够集成 MCP 工具扩展 Agent 能力
- [ ] 能够调试和优化 Agent 性能
- [ ] 完成一个综合项目（智能旅行助手或自选项目）

### 产出目标
- [ ] 完整的学习笔记
- [ ] 可运行的代码示例
- [ ] 一个完整的 Agent 项目
- [ ] 可选：提交到 Co-creation-projects

## 🗓️ 四周计划总览

### Week 1：环境搭建 + 快速入门
- **主题**：搭建开发环境，运行第一个 Agent
- **重点**：理解 ReAct 范式
- **产出**：成功运行 FirstAgentTest.py 和 ReAct.py

### Week 2：框架实践
- **主题**：掌握 HelloAgents 框架，体验主流框架
- **重点**：自定义 Agent 和工具
- **产出**：使用框架构建简单 Agent

### Week 3：高级主题 + MCP 协议
- **主题**：MCP 协议集成、记忆系统
- **重点**：工具集成能力扩展
- **产出**：集成 MCP 工具的 Agent

### Week 4：项目实战
- **主题**：综合项目开发
- **重点**：智能旅行助手或自选项目
- **产出**：完整的 Agent 应用

## 📋 学习方法

### AI 辅助 vs 自主学习分类

| 类型 | 内容 | 方式 | 时间占比 |
|------|------|------|----------|
| 🤖 **AI 辅助** | 文档总结、代码解释、调试帮助、概念对比 | 提问 AI | 40% |
| 🧠 **自主学习** | 动手实践、修改代码、项目开发、深度思考 | 亲自操作 | 60% |
