**核心要点记录** 🧠：

```
ReAct 范式 = Reasoning + Acting

核心循环：
Thought → Action → Observation → Thought → Action → ...

优点：
1. 可解释性强（有思考过程）
2. 能利用外部工具
3. 灵活性高

缺点：
1. 可能陷入死循环
2. Token 消耗较多
3. 依赖提示词质量

适用场景：
- 需要调用外部工具的任务
- 需要多步推理的任务
- 需要可解释性的场景
```

### 任务 6：三种范式对比分析

**AI 辅助学习** 🤖：

```
请对比 Agent 的三种经典范式：ReAct、Reflection、Plan-and-Solve

请用表格形式对比：
1. 核心思想

3. 优点

5. 适用场景
6. 代码复杂度

并给出选择建议：在什么情况下应该选择哪种范式？
```

**对比表格** 🧠：

| 维度 | ReAct | Reflection | Plan-and-Solve |
|------|-------|------------|----------------|
| **核心思想** | 思考-行动-观察循环 | 自我反思改进 | 先规划后执行 |
| **执行流程** | 循环执行单步任务 | 生成→反思→改进 | 规划→分解→执行 |
| **优点** | 灵活、可解释 | 质量高、深度思考 | 有序、可追踪 |
| **缺点** | 可能循环过多 | 慢、成本高 | 不够灵活 |
| **适用场景** | 工具调用任务 | 需要高质量输出 | 复杂多步骤任务 |
| **复杂度** | 中等 | 较高 | 较高 |

**选择决策树** 🧠：

```
任务需要外部工具？
├── 是 → 推荐使用 ReAct
└── 否 → 任务复杂度如何？
         ├── 简单 → 直接 LLM
         ├── 中等 → 使用 Reflection 提高质量
         └── 复杂 → 使用 Plan-and-Solve 分解任务
```
