## 📚 核心知识点

### 1. Agent 基本概念
- Agent 定义：能够感知环境、做出决策、执行行动的智能体
- Agent 类型：单智能体 vs 多智能体
- Agent 核心：LLM + 记忆 + 工具 + 规划

### 2. ReAct 范式
```
┌─────────────────────────────────────────┐
│              ReAct 循环                  │
├─────────────────────────────────────────┤
│                                         │
│    ┌─────────┐                          │
│    │ Question│                          │
│    └────┬────┘                          │
│         ↓                               │
│    ┌─────────┐                          │
│    │ Thought │ ← 思考：分析问题          │
│    └────┬────┘                          │
│         ↓                               │
│    ┌─────────┐                          │
│    │ Action  │ ← 行动：调用工具          │
│    └────┬────┘                          │
│         ↓                               │
│    ┌─────────┐                          │
│    │Observation│ ← 观察：获取结果        │
│    └────┬────┘                          │
│         │                               │
│    ┌────↓────┐                          │
│    │ 继续循环？│                          │
│    └────┬────┘                          │
│         │                               │
│    ┌────↓────┐                          │
│    │ Finish  │ ← 最终答案               │
│    └─────────┘                          │
│                                         │
└─────────────────────────────────────────┘
```

### 3. 三种范式对比

| 范式 | 核心思想 | 适用场景 |
|------|----------|----------|
| **ReAct** | 思考-行动-观察循环 | 需要外部工具的任务 |
| **Reflection** | 自我反思和改进 | 需要迭代优化的任务 |
| **Plan-and-Solve** | 先规划后执行 | 复杂多步骤任务 |
